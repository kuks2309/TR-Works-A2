## Core 인벤토리

### 1. 목적

`openarmx_gravity_comp` 는 OpenArmX 양팔(bimanual) 로봇의 **중력 피드포워드(feedforward) 보상** 노드다. MIT(Massachusetts Institute of Technology, 모터 제어 모드) 모드의 순수 PD(Proportional-Derivative) 제어는 적분항이 없어 중력에 의한 정상상태 처짐(약 6°)이 발생한다(README_kr.md:9·24). 본 노드는 `/joint_states` 를 구독하여 매 수신마다 KDL(Kinematics and Dynamics Library) 재귀 뉴턴-오일러로 자세별 중력 토크 `g(q)` 를 실시간 계산하고, `g_scale` 로 스케일·`TAU_LIMITS` 로 클램프한 뒤 `/<side>_forward_effort_controller/commands` 로 발행한다. 이 값이 `forward_command_controller` → `v10_simple_hardware.cpp` write() 의 MIT `τ_ff` 에 주입되어 처짐을 1° 이내로 줄인다(README_kr.md:29·237-239).

구조는 두 층이다: ① ROS2 노드 `GravityCompNode`(구독·계산·발행·런타임 파라미터) — `gravity_comp_node.cpp`, ② KDL 래퍼 `Dynamics` 클래스(URDF 파싱→KDL 체인→`JntToGravity`) — `dynamics.cpp`/`dynamics.hpp`. 좌/우 팔 각각 독립 `Dynamics` 인스턴스를 갖고, base 가 X축 ±90° 장착이라 월드 `-Z` 중력이 link0 에서 Y축이 되는 좌표 규약을 부호로 흡수한다(gravity_comp_node.cpp:33-40).

### 2. 코드 플로우차트

본 패키지는 진입점이 1개(`main`→spin)이고, 동작은 **초기화 1회** + **콜백 반복**으로 나뉜다. 두 경로를 분리한다.

#### 2-A. 초기화 경로 (`GravityCompNode` 생성자)

```mermaid
flowchart TD
    start([main: rclcpp::init]) --> ctor[GravityCompNode 생성자]
    ctor --> decl[파라미터 declare/get<br/>urdf_path·g_scale·enable_left/right·verbose·enable_compensation]
    decl --> chkurdf{urdf_path 비었나?}
    chkurdf -->|예| fatal1[RCLCPP_FATAL + throw runtime_error]
    fatal1 --> catchmain[main catch → return 1]
    chkurdf -->|아니오| enL{enable_left?}
    enL -->|예| initL[left_dyn_ = Dynamics<br/>left_link0→left_link7<br/>Init + SetGravityVector 0,+9.81,0]
    initL --> initLok{Init 성공?}
    initLok -->|실패| fatal2[FATAL + throw]
    fatal2 --> catchmain
    initLok -->|성공| enR
    enL -->|아니오| enR{enable_right?}
    enR -->|예| initR[right_dyn_ = Dynamics<br/>right_link0→right_link7<br/>Init + SetGravityVector 0,-9.81,0]
    initR --> enRok{Init 성공?}
    enRok -->|실패| fatal2
    enRok -->|성공| pub
    enR -->|아니오| pub[좌/우 effort 커맨드 Publisher 생성]

    pcb --> sub[/joint_states 구독 생성 depth=10/]
    sub --> spin([rclcpp::spin 대기])
```

#### 2-B. 런타임 경로 (`joint_state_callback` → `publish_gravity_torques`, 팔마다 1회)

```mermaid
flowchart TD
    js([/joint_states 수신]) --> cbL{enable_left_ && left_dyn_?}
    cbL -->|예| pgtL[publish_gravity_torques LEFT]
    cbL -->|아니오| cbR
    pgtL --> cbR{enable_right_ && right_dyn_?}
    cbR -->|예| pgtR[publish_gravity_torques RIGHT]
    cbR -->|아니오| done([콜백 종료])
    pgtR --> done

    subgraph PGT["publish_gravity_torques (ndof=7)"]
      direction TB
      encomp{enable_compensation_?}
      encomp -->|false| zeros[out = 7×0.0 발행 후 return<br/>잔여 feedforward 클리어]
      encomp -->|true| loopmap[관절 j=0..6 이름으로 msg 인덱스 검색]
      loopmap --> found{이름 존재 &&<br/>idx < position.size?}
      found -->|아니오| skip[return — 이번 사이클 스킵<br/>해당 팔 미발행]
      found -->|예| qfill["q[j] = msg.position[idx]"]
      qfill --> grav["dyn.GetGravity(q, tau_g)<br/>KDL JntToGravity"]
      grav --> loopclamp[관절 j=0..6:<br/>tau = g_scale_ × tau_g_j<br/>clamp ±TAU_LIMITS_j]
      loopclamp --> vb{verbose_?}
      vb -->|예| log[THROTTLE 1s 관절별 로그]
      vb -->|아니오| pubout
      log --> pubout[Float64MultiArray 발행]
    end
```
