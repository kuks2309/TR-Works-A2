# 2026-06-03

## Pilz 패키지 테스트가 목표인데 cyclo 시나리오 스택을 실행함

### 상황
`openarmx_pilz_box_align`(Pilz / MoveIt 백엔드) end-to-end 테스트가 목표였다.
cyclo 변형(`openarmx_cyclo_box_align`)은 이미 `AlignToBoxes` goal로 양팔 0mm 도달
테스트 완료 상태였다. 사용자의 "시나리오 RViz 실행" 요청에
`scenario_player_with_ee_leader.launch.py`(= cyclo MoveL 컨트롤러 스택)를 실행했다.
그러나 Pilz는 MoveIt `move_group` + `/plan_kinematic_path` 서비스가 필요한데
cyclo 시나리오 스택에는 move_group이 없어, 띄운 스택으로는 Pilz를 테스트할 수 없었다.

### 원인
요청의 "시나리오"라는 단어에만 맞춰 scenario_player(cyclo) 스택을 실행하고,
**현재 테스트 목표(Pilz)가 요구하는 모션 백엔드(MoveIt)와 정렬하지 않음.**
또 cyclo 변형이 이미 테스트 완료라 cyclo 스택을 재기동할 이유가 없었음을 간과.

### 재발 방지
- 특정 백엔드 패키지를 테스트할 땐 **그 백엔드의 스택**을 띄운다:
  cyclo box_align → cyclo 시나리오 스택, **pilz box_align → MoveIt move_group 스택**.
- "시나리오 RViz 실행"처럼 모호한 요청은 **현재 작업 목표(무엇을 테스트하는지)와
  연결**해 어느 스택/백엔드인지 확인한 뒤 실행한다.
- 이미 검증 완료된 것을 다시 띄우고 있지 않은지 먼저 점검한다.
