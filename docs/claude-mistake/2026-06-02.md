# 2026-06-02 Claude 실수 기록

## 2026-06-02 15:40 (KST) — 마커 UI 저성의 재디자인 + 서브탭 표기 비일관

### 무엇을 했는가
openarmx_scenario_ui Cartesian Control 탭 작업.
1. "Jog 탭 참조해서 마커 UI 다시 만들어" 지시에, 마커 좌표를 **모노스페이스 텍스트 2줄 + 작은 폰트(11~14px)**로 표시하고 끝냄.
2. 1차 거부 후 셀 그리드로 바꿨으나 글자 크기를 여전히 작게 둠.
3. Marker 탭만 새 스타일로 바꿔, 같은 부모 아래 Marker/Jog/Manual 서브탭이 좌표를 **제각각 표기**(Marker=회색 셀 x/y/z, Jog=관절각만, Manual=Δx 스핀박스+인라인 단위)하게 됨.

### 무엇이 잘못이었나
- 참조(Jog 탭)는 값마다 **회색 셀 박스 + 라벨 + 기본(큰) 폰트** 그리드인데, 미러링하지 않고 최소 텍스트로 처리 → "성의 없음".
- 폰트 크기를 임의 축소해 참조와 시각 무게가 안 맞음.
- 한 컴포넌트(Marker)만 손대 서브탭 간 표기 일관성을 깨뜨림.

### 사용자 지적
- "비교해보면 너가 marker를 얼마나 성의 없이 대충 만든지 판단할 수 있을 거야"
- "글자 크기 부터 성의가 없잖아"
- "일관성이 없음 서브 탭인데 탭 마다 다른 표기 방식.. 이게 맞다고 생각해?"

### 사유 / 가설
- "참조해서 만들라"를 *기능 복제*가 아닌 *대충 비슷하게*로 해석. 참조 위젯의 스타일시트(`_build_arm_jog_group` joint 셀 QSS)를 먼저 읽고 그대로 쓰지 않음.
- 폰트 크기를 "정보 밀도" 명목으로 줄였으나 참조는 기본 크기 사용 → 불일치.
- 작업 범위를 "지시받은 탭(Marker)"으로만 좁혀, 형제 서브탭과의 전역 일관성을 고려 안 함.

### 재발 방지
- UI "X 참조/일관" 지시 시: ① 참조 컴포넌트 스타일시트를 먼저 읽고 그대로 미러링, ② 폰트 크기 임의 축소 금지, ③ 같은 부모 아래 서브탭은 값 표기를 **단일 근원(공유 QSS 상수)**으로 통일.
- 반영 자산:
  - 공유 상수 `VALUE_CELL_QSS`/`AXIS_LABEL_QSS` + `<b>섹션(단위)</b>` 헤더를 Marker/Jog/Manual 3탭이 공유 — [cartesian_control_tab.py](../../openarmx_ws/src/openarmx_ros2/openarmx_scenario_ui/openarmx_scenario_ui/cartesian_control_tab.py)
  - 메모리 `feedback_ui_consistency_mirror.md` (UI 미러링·서브탭 표기 통일 규칙)
